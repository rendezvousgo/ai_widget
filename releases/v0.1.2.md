## ✨ What's new in v0.1.2

### Visual
- **New app icon** — diamond + ripple monochrome design. Charcoal squircle, faceted diamond core, three fading ripple rings around it. Replaces the prior default Tauri logo.

### Reliability
- **Stale-cache fallback** on transient API failures. When Anthropic's OAuth usage endpoint returns a network error, 5xx, 429, or unparseable response, the widget now serves the most recently cached data (up to 1 hour old) instead of flashing an error at you. Once the next refresh succeeds the data goes back to live.
