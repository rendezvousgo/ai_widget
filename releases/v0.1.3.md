## ✨ What's new in v0.1.3

### Window controls
- **Pin button (📌)** — toggles always-on-top *and* locks the window in place so you can't accidentally drag it. Click again to release.
- **Minimize button (−)** — minimizes the widget to the taskbar like a normal app.

### Reliability
- **Polling interval** bumped from 45 s → 90 s. The Anthropic OAuth usage endpoint was returning 429 (rate-limit) too often at the previous cadence; the wider window makes those errors much rarer while still feeling fresh.

### Already in 0.1.2 (recap, since 0.1.2 was a quick re-tag)
- New diamond + ripple monochrome icon (charcoal squircle, faceted diamond core, 3 fading ripple rings).
- Stale-cache fallback (up to 1 h) on transient network / 5xx / 429 errors so the widget doesn't flash an error at you.
- Self-collected usage history (`~/.config/ai-quota-widget/usage_history.jsonl`) used as the Trend tab's data source when no daily JSONL is available.
