## ✨ Initial release — v0.1.0

Quota is a small desktop widget that shows your Claude (Pro / Max) and OpenAI usage at a glance, without sitting in a browser tab.

### What's in this build
- **Tauri 2 + Svelte 5** native widget — runs as a small floating window, not a tray icon.
- **Claude plan tracking** — reads `~/.claude/.credentials.json` written by the Claude Code CLI and queries the OAuth `usage` endpoint for 5-hour and weekly utilization.
- **OpenAI quota tracking** — bring your own API key (stored locally in the app's config dir) to surface remaining quota.
- **Cross-platform** — Linux (deb / rpm / AppImage) and Windows (NSIS installer / MSI).
- **Portable single-exe** bundles for both platforms — no installer required if you'd rather not.

### Downloads
- **Linux** — `AI.Quota.Widget_0.1.0_amd64.AppImage` (or `.deb` / `.rpm`), or `Quota-v0.1.0-linux-portable.tar.gz`
- **Windows** — `AI.Quota.Widget_0.1.0_x64-setup.exe` (NSIS) / `AI.Quota.Widget_0.1.0_x64_en-US.msi` (MSI), or `Quota-v0.1.0-windows-portable.zip`
