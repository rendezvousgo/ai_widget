## ✨ What's new in v0.1.1

### Windows fixes
- **Drag region** now works reliably across the whole header on Windows — no more dead zones when trying to move the widget.
- **No console flash** during Claude login polling. Earlier we shelled out via `cmd /C where claude` every 10 s, which popped a black box on screen — replaced with an in-process PATH walk so polling is silent.

### Trend tab
- **Better empty state** when no usage history exists yet — clearer hint text instead of an unexplained blank.
- **Self-collected usage history** as a fallback data source — when no `~/.claude/projects/**/*.jsonl` daily counts are available, the trend chart falls back to snapshots the widget itself has been recording every ~5 min while running.
