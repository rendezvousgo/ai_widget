## ✨ What's new in v0.1.4

### ChatGPT subscription usage
- **ChatGPT Plus/Pro plan tracking** — reads Codex CLI credentials (`~/.codex/auth.json`) and queries the ChatGPT `wham/usage` endpoint for 5-hour and weekly utilization, same as Claude.
- **Trend tab** for OpenAI — daily token counts and message totals pulled from Codex CLI's local session database (`~/.codex/state_5.sqlite`). Shows the same Peak / Avg / Total / Msgs stats as Claude.
- **Self-collected usage snapshots** — `~/.config/ai-quota-widget/chatgpt_usage_history.jsonl`, same 5-min cadence as Claude.

### Service status
- **Status tab** (Now · Trend · **Status**) for both Claude and OpenAI. Pulls from the public Statuspage APIs (`status.claude.com`, `status.openai.com`) — no auth needed.
- Components grouped by category (Web / Developer / Code / API / Media / Infra).
- Active incidents shown inline. Donut ring summary with operational count.
- **"status page ↗"** link opens the real status site in the browser.

### Plan renewal date
- **Subscription renewal date** displayed next to the plan name (e.g., `Max 5× resets 2026-06-01 (7d)`).
- Claude: calculated from `~/.claude.json` → `subscriptionCreatedAt`.
- ChatGPT: fetched from `accounts/check` API (cached locally).
- **Timezone setting** (KST / UTC) in Settings — renewal date adjusts accordingly.

### Polling
- Auto-refresh interval bumped from 45 s → **90 s** to reduce 429 rate-limit errors from Anthropic's OAuth usage endpoint.
